# RulesLawyer Data Files

The RulesLawyer service requires **embedding data files** for each rulebook you want to query. These files are **not** included in the repository and must be placed in this directory.

## Required Files

For each embedding ID (e.g., `DnD_PHB_55`), you need:

1. **`{embedding_id}_embeddings.csv`** - Pre-computed embeddings of rulebook text chunks
2. **`{embedding_id}.json`** - Enhanced metadata with page summaries

### Example

For embedding ID `DnD_PHB_55`, place these files in `DungeonMindServer/ruleslawyer/`:
- `DnD_PHB_55_embeddings.csv`
- `DnD_PHB_55.json`

## File Locations

**Expected location:** `DungeonMindServer/ruleslawyer/`

The backend looks for files in this directory based on the paths sent from the frontend:
- Frontend sends: `embeddings_file_path: "DnD_PHB_55_embeddings.csv"`
- Backend resolves to: `DungeonMindServer/ruleslawyer/DnD_PHB_55_embeddings.csv`

## CSV File Format

The embeddings CSV should have columns:
- `embedding` - JSON-stringified array of embedding vectors (1024 dimensions for BAAI/bge-m3)
- Other columns (e.g., `page`, `chunk`, `text`) for metadata

Example structure:
```csv
page,chunk,text,embedding
1,0,"Introduction text...","[0.123, -0.456, ...]"
1,1,"More text...","[0.789, -0.012, ...]"
```

## JSON File Format

The enhanced JSON should have:
```json
{
  "document_summary": "Overall summary of the rulebook",
  "pages": {
    "1": {
      "summary": "Page 1 summary"
    },
    "2": {
      "summary": "Page 2 summary"
    }
  }
}
```

## Generating These Files

These files are typically generated by:
1. Extracting text from PDF rulebooks
2. Chunking the text into manageable pieces
3. Generating embeddings using the BAAI/bge-m3 model
4. Creating page summaries

**Note:** The generation process is separate from this codebase. You'll need to create these files using your own PDF processing and embedding generation pipeline.

## Current Status

Check if files exist:
```bash
ls -lh DungeonMindServer/ruleslawyer/*.csv
ls -lh DungeonMindServer/ruleslawyer/*.json
```

If files are missing, you'll get a 404 error when trying to load embeddings:
```
Embeddings file not found: /path/to/DungeonMindServer/ruleslawyer/DnD_PHB_55_embeddings.csv
```
